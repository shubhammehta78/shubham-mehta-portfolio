# Shubham Mehta — Portfolio

Personal portfolio for **Shubham Mehta**, a Senior React Native Engineer with 7.5+ years of experience building iOS and Android applications.

## Direction

This portfolio showcases independent projects and intentionally does **not** expose confidential employer work.

### Featured projects

- **ShopSphere** — e-commerce mobile app
- **StockPilot** — offline-first inventory and field operations
- **FinSight AI** — AI-powered personal finance
- **FitTrack** — fitness and progress tracking

## Stack

- React
- TypeScript
- Vite
- Custom CSS
- Responsive web UI

## Run locally

```bash
npm install
npm run dev
```

Vite will print the local development URL in the terminal.

## Build

```bash
npm run build
npm run preview
```
