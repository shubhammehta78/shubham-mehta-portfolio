# Portfolio project instructions

## Purpose
This repository is the public portfolio of Shubham Mehta, a Senior React Native Engineer.

## Non-negotiable privacy rule
Never add, infer, reproduce, or expose confidential employer information. Do not include proprietary screenshots, source code, internal architecture diagrams, customer data, internal metrics, business logic, or company-specific workflows.

Professional experience may be described only at a high level using information intentionally provided for the public portfolio.

## Product direction
The portfolio will showcase independent projects:
- ShopSphere
- StockPilot
- FinSight AI
- FitTrack

Keep the visual language premium, technical and product-focused. Prioritize responsive UX, accessibility, performance, semantic HTML and maintainable TypeScript.

## Engineering expectations
- Keep components small and understandable.
- Prefer server components unless client interactivity is actually needed.
- Avoid unnecessary dependencies.
- Add meaningful loading, empty and error states as projects become functional.
- Verify builds before declaring a task complete.
